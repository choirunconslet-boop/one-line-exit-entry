# The One-Line Exit

One funny single-line resignation letter, written for the make.fun bounty
`u-kreutzx-the-one-line-exit-1dc652d1`.

## The line

> I resign, effective immediately, to pursue my dream of never explaining to a grown adult how to attach a file to an email again.

## How to run

Requires Node 22.18+ (runs TypeScript as-is):

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (128 characters, one line, no
trailing newline).
